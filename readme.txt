Blocs Gutenberg de carrousel basés sur Splide : slider libre et carrousel de publications.

== Description ==

* Ufo Splide Slider : slider de blocs libres (glissement ou fondu).
* Ufo Splide Posts : carrousel de publications ou de Custom Post Types.

Voir README.md pour la documentation complète.

== Installation ==

1. Copier le dossier dans `/wp-content/plugins/ufo-splide-blocks`.
2. Activer le plugin dans l'écran Extensions.
